Architettura

Origine statica su 127.0.0.1:8777 esposta via reverse tunnel SSH su porta 443. Nessun dato lascia la rete di origine se non il traffico HTTP verso questa pagina.

Stack

python http.server (stdlib, zero dipendenze) + OpenSSH + Pinggy. Tutto gratuito, nessun account, nessun servizio cloud a pagamento.

Stato

Connessione attiva. La sessione è viva finché il tunnel resta aperto.
